## 一、问题现象

Agent 自动执行构建命令时出现两条错误：

### 错误 1 — Bash 环境（`cd /d` 语法不兼容）

```bash
# Agent 生成的命令
Bash(cd /d C:\Users\Administrator\Documents\Codex\ClawRouter && node node_modules/tsup/dist/cli.js src/cli-api-key.ts --format esm --out-dir dist/)
```

```
/usr/bin/bash: line 1: cd: too many arguments
[rtk] shell wrapping active — all supported commands auto-routed through rtk
```

### 错误 2 — PowerShell 环境（入口路径不存在）

```bash
# Agent 生成的命令
PowerShell(node node_modules\tsup\dist\cli.js src/cli-api-key.ts --format esm --out-dir dist\)
```

```
Error: Cannot find module 'C:\Users\Administrator\Documents\Codex\ClawRouter\node_modules\tsup\dist\cli.js'
```

---

## 二、根因分析

### 1. Bash 报错根因

- `cd /d ...` 是 **Windows cmd.exe 语法**，不属于 POSIX Bash。
- RTK 的 `.bashrc` 注入了一套命令包装函数（`git`、`npm`、`pnpm`、`python` 等 → `rtk xxx`），导致所有命令被自动路由到 Bash 执行。
- 在 Bash 环境下，`cd /d` 把 `/d` 当作路径参数，导致"too many arguments"。

### 2. PowerShell 报错根因

- 当前 `tsup@8.5.1` 的 CLI 入口是 `dist/cli-default.js`，**不是** `dist/cli.js`。
- Agent 硬编码了旧版入口路径，导致 Node 找不到模块。

### 3. 配置层叠问题

检查发现三处重复接管，造成不可预期行为：

| 配置位置 | 行为 | 状态 |
|---|---|---|
| `C:\Users\Administrator\.bashrc` | 全量命令自动包装（`git`→`rtk git` 等）+ 输出 `[rtk] shell wrapping active` | ⚠️ 污染 Bash 语义 |
| `C:\Users\Administrator\.claude\settings.json` 的 `PreToolUse` | `Bash` 工具触发 `rtk hook claude` | ⚠️ 双重拦截 |
| `rtk config.toml` | 默认配置，无问题 | ✅ 正常 |

此外，`C:\Users\Administrator\.bashrc` 文件含 **54 个 NUL 字节**编码损坏，末尾 alias 行已乱码。

---

## 三、修复方案

### 方案 A（推荐）：统一用 `npx --prefix` 绝对路径

```powershell
npx --prefix "C:\Users\Administrator\Documents\Codex\ClawRouter" tsup "C:\Users\Administrator\Documents\Codex\ClawRouter\src\cli-api-key.ts" --format esm --out-dir "C:\Users\Administrator\Documents\Codex\ClawRouter\dist"
```

优点：
- `--prefix` 指定项目根，无需 `cd` 切换目录
- `npx tsup` 用包内注册的可执行入口，兼容任何 tsup 版本
- 不依赖硬编码 `node_modules/tsup/dist/cli.js`

### 方案 B（长期）：在 `CLAUDE.md` 中锁定标准构建命令

在 `C:\Users\Administrator\.claude\CLAUDE.md` 或项目级 `CLAUDE.md` 中增加规则：

```
## 构建规范
- Windows 构建：统一使用 `npx --prefix <项目根> tsup <源文件> --format esm --out-dir <输出目录>`
- 禁止硬编码 `node_modules/tsup/dist/cli.js`
- 禁止使用 `cd /d`（Windows cmd 语法）
- 优先 `npx` / `npm run` 调用构建命令
```

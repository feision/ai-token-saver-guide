# RTK Windows Wrapper PowerShell Cmdlet 修复报告

> 日期：2026-05-28
> 问题：PowerShell cmdlet 被 rtk 路由到 Bash 执行，报 `command not found`
> 状态：✅ 已修复

---

## 一、问题现象

Agent 执行 PowerShell 命令：

```
PowerShell(Get-Process | Select-Object -First 20)
```

rtk-windows-wrapper.js 放行 → 进入 bash → 报错：

```
/usr/bin/bash: line 2: Select-Object: command not found
/usr/bin/bash: line 2: Select-String: command not found
```

---

## 二、根因分析

`rtk-windows-wrapper.js` 原有逻辑只处理 Windows 可执行文件名映射：

```javascript
const winCmdMap = {
  move: "mv",
  del: "rm",
  ...
};
```

`Select-Object` / `Select-String` 是 PowerShell **cmdlet**，不是 .exe，wrapper 不识别，直接透传给 bash → 报错。

---

## 三、修复方案

### 1. 新增 PowerShell cmdlet 模式检测

```javascript
const psPatterns = [
  /^(select|where|foreach|get|set|new|remove|add|clear|test|start|stop|invoke|write|read|out|format|convertto|convertfrom|import|export|enter|exit|push|pop)-/i,
  /\|$/,           // pipeline
  /\$\w+/,         // PS 变量
  /\{\s*\$\w+/,    // script block
  /-eq |-ne |-gt |-lt |-le |-ge /,  // PS 比较操作符
  /-match |-notmatch /,
  /-contains |-notcontains /,
  /-in |-notin /,
  /% /,            // ForEach-Object 别名
  /\?\{/,          // Where-Object 别名
];
```

### 2. 检测后改写工具类型

```javascript
if (isPowerShellCommand(command)) {
  json.tool = "PowerShell";  // Bash → PowerShell
}
```

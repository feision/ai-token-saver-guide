# RTK Shell Wrapping 修复报告

> 日期：2026-05-26
> 问题：PowerShell cmdlet 在 Bash 环境执行，报 `command not found`
> 状态：✅ 已修复

---

## 一、问题现象

Agent 执行命令时出现两条错误：

### 错误 1 — PowerShell 命令跑在 Bash

```
Bash(pwd; Get-Location)
Error: Exit code 127
/usr/bin/bash: line 2: Get-Location: command not found
[rtk] shell wrapping active — all supported commands auto-routed through rtk
```

### 错误 2 — 目录不存在

```
Bash(cd /c/Users/Administrator/Documents/Codex && ls -la app/*/)
Error: Exit code 2
ls: cannot access 'app/*/': No such file or directory
```

---

## 二、根因分析

| 问题 | 原因 |
|------|------|
| PowerShell 命令跑在 Bash | `.bashrc` 含 22 个命令包装函数（`git`、`npm`、`pnpm` 等），所有命令被拦截转发到 Bash 执行 |
| `Get-Location` 找不到 | PowerShell cmdlet 在 Git Bash 环境不存在 |
| shell wrapping active | RTK 通过 `.bashrc` 注入包装函数 |

### 配置层叠问题

| 配置位置 | 行为 | 状态 |
|----------|------|------|
| `~/.bashrc` | 全量命令包装（`git`→`rtk git` 等） | ⚠️ 污染 Bash 语义 |
| `~/.claude/settings.json` PreToolUse | `rtk-windows-wrapper.js` hook | ✅ 正常 |
| `~/.claude/hooks/rtk-windows-wrapper.js` | Windows 命令转换 | ✅ 存在 |

**问题**：`.bashrc` 包装函数拦截命令，但 Bash 环境无法识别 PowerShell cmdlet。

---

## 三、修复步骤

### 1. 备份原文件

```powershell
Copy-Item "$env:USERPROFILE\.bashrc" "$env:USERPROFILE\.bashrc.backup-20260526-xxxxxx"
```

### 2. 清理 `.bashrc`

删除 22 个命令包装函数，保留：

```bash
# .bashrc - clean version (RTK wrapping removed)

# Set PATH
export PATH="$PATH:/c/Users/Administrator/bin"

# Aliases (no RTK wrapping)
alias ll='ls -la'
alias gs='git status'

# Sentinel to prevent double-wrapping (used by wrapper)
export RTK_WRAPPED=0
```
